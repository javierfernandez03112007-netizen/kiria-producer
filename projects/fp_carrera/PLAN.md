# Plan visual — «FP o carrera de Informática» (palabra → forma)

Objetivo: polémica sana y comentarios. Formato combate: dos bandos con marcador, cada dato suma un punto, veredicto al
final y pregunta directa para que cada uno defienda su equipo. Estilo: el de `carga/` (espacio 3D negro con flujo óptico,
HUD técnico en blanco y grises); color de bando: FP = turquesa, CARRERA = ámbar. Marcador fijo arriba: «FP 0 — 0 CARRERA».

| Voz | Qué se ve |
|---|---|
| «Para trabajar de programador en España, la ley no te exige ningún título» (0–1 s, hook) | Dos títulos enrollados (FP y carrera) vuelan hacia cámara y se rompen en el aire en mil pedazos; sello HUD «NO OBLIGATORIO». |
| «Ni carrera, ni FP» | Los trozos se separan en dos nubes, turquesa a la izquierda y ámbar a la derecha. |
| «FP o carrera es una guerra eterna» | Las nubes se convierten en dos podios enfrentados en un ring de luz; aparece el marcador 0–0. |
| «Al final te digo quién gana… y a un bando no le va a gustar» | Un trofeo tapado gira en el centro con «?». |
| «Los de FP dicen: dos años, prácticas en empresa y a trabajar» | Bloque turquesa de 2 cubos + un maletín; terminal «FP › 2 AÑOS + PRÁCTICAS». |
| «Vosotros, cuatro años de teoría» | Bloque ámbar de 4 cubos que se llena de pizarras con fórmulas. |
| «sabéis usar herramientas, pero no entendéis lo que hay debajo» | Una llave inglesa turquesa; la cámara baja bajo el suelo y aparecen engranajes y circuitos «debajo». |
| «¿Quién tiene razón? Datos.» | El ring se aplana en una tabla de datos (flujo óptico fuerte). |
| «casi la mitad piden FP. Solo una de cada cinco pide carrera» | Lluvia de ofertas (tarjetas) que caen y se apilan: 47 % turquesa, 21 % ámbar; rótulo «INFOEMPLEO ADECCO». |
| «Punto para FP» | Marcador 1–0 con golpe y destello. |
| «en las oposiciones, los puestos del grupo A exigen carrera. Con FP, como mucho, el grupo B» | Escalera de puertas A1, A2, B, C1: la llave ámbar abre A; la turquesa se queda en B. |
| «sin carrera no hay máster universitario» | Una puerta «MÁSTER» que solo se abre con la llave ámbar. |
| «Punto para la carrera» | Marcador 1–1. |
| «la Ingeniería Informática ni siquiera es una profesión regulada. Industrial o Teleco, sí» | Documento HUD «PROFESIONES REGULADAS»: Industrial ✓, Telecomunicación ✓, Informática ✕ en rojo. |
| «cada una pide lo que quiere» | Muchas oficinas en miniatura, cada una con su cartel distinto. |
| «Entonces, ¿quién gana?» | Vuelve el trofeo tapado; zoom rápido. |
| «Para empezar a trabajar antes, FP. Para tener más puertas abiertas, carrera» | Pantalla partida: cohete turquesa que sale antes / pasillo ámbar con muchas puertas. |
| «la jugada maestra: las dos… sin selectividad y con medio curso convalidado» | El título turquesa se convierte en puente hacia la universidad; «−30 ECTS» en el puente; el trofeo se destapa con los dos colores. |
| «¿Equipo FP o equipo carrera? Defiéndelo en comentarios.» | Dos botones enormes «EQUIPO FP» / «EQUIPO CARRERA» y vuelta a los títulos en el aire (bucle). |
